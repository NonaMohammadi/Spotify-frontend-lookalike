# Spotify Frontend Lookalike

A front-end clone of the Spotify web app, built with plain HTML and CSS.

## Pages

- `login.html` – Login screen
- `main.html` – Home / dashboard view
- `playlist.html` – Playlist view
- `aurora.html` – Additional page
- `styles.css` – Shared styling
- `img/` – Images and icons used across the pages

## Getting Started

No build tools or dependencies required — this is a static HTML/CSS project.

1. Clone the repo:
   ```bash
   git clone https://github.com/NonaMohammadi/Spotify-frontend-lookalike.git
   ```
2. Open any of the `.html` files directly in your browser, starting with `login.html`.
